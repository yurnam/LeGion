# Security Policy

## Safety goals

This project is intended to reduce the information value of passive Wi-Fi
fingerprinting without disrupting client connectivity or transmitting harmful
management traffic.

The initial codebase enforces conservative input bounds and only implements the
relay/bootstrap layer. It does not include deauthentication, association,
credential capture, traffic interception, or jamming functionality.

## Reporting issues

Please report vulnerabilities through GitHub Security Advisories or a private
maintainer contact channel before opening a public issue.
